## What is ReportGen?
ReportGen is a web application that organizes form data into structured PDF reports. It focuses on user-friendliness, providing a straightforward and "no-fluff" interface that makes project generation hassle-free. Generated projects are stored persistently, allowing authenticated users to view, edit, and delete them.

## Features

- User registration and authentication
- Dynamic project and module forms
- Project preview before PDF generation
- PDF report generation
- Persistent project storage
- View, edit, and delete saved projects
- Minimal and interactive user interface

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Backend:** Python, Flask
- **Database:** SQLite
- **PDF Generation:** ReportLab
- **Deployment:** Railway
